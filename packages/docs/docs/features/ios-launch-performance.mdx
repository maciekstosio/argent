Argent can measure an iOS app launch and record an Xcode Instruments App Launch trace. Argent builds the app in Release for both tasks. Select a connected iPhone for device measurements.

The launch measurement uses an Argent UI test runner. The runner measures five launches with Apple's application launch metric. Argent keeps the app project unchanged.

The Instruments recording shows the launch phases up to the first frame. Argent returns these phases and keeps the CPU samples of the launch as a native profiler session. The agent then uses the profiler query tools to find the functions that delay the first frame.

Argent prepares a warm launch before each task. A warm launch starts a new app process after the app has already run on the device. This measurement does not describe a cold launch or a resume from the background.

Measure on a physical iPhone when you need device performance. A simulator uses Mac hardware, so its timings can differ from iPhone timings. Argent uses a simulator only when you allow it.

Argent saves each run under `.argent/traces/<datetime>/` in the app project. The measurement keeps its Xcode result and logs. The Instruments run keeps the trace and its lifecycle and dyld exports. Argent keeps the CPU samples of the launch in the native profiler session.

See the [tools reference](/docs/reference/tools#ios-launch-performance) for parameters and signing behavior.
